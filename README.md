# 🎬 Basic Camera Shots — Image Study

A beginner-friendly AI cinematography project exploring cinematic camera shots, framing, composition, and visual storytelling through AI-generated images.

---

## 🌧️ Project Concept

This project studies how different camera shots influence storytelling and emotional impact using a single cinematic scene:

> *“A girl waiting at a rainy bus stop at night.”*

The same subject and environment are recreated using multiple cinematic camera shots to understand how framing and perspective affect mood, composition, and storytelling.

---

## 📷 Camera Shots Explored

- Wide Shot
- Medium Shot
- Close Up
- Extreme Close Up
- Low Angle Shot
- High Angle Shot
- Over The Shoulder Shot
- Bird’s Eye View

---

## 🎯 Objective

The goal of this project is to learn and practice:

- Cinematic composition
- Camera framing techniques
- Visual storytelling
- Lighting and atmosphere
- Prompt engineering
- Scene consistency in AI-generated visuals

---

## 🧠 Workflow

Each shot includes:

1. A manually written prompt
2. An AI-assisted prompt
3. Generated image outputs
4. Comparative observations and analysis
